# RollCall Example — Real-World GAS Webapp

This folder is a **worked example** for the skills in this collection. Original project: `van90bg/attendance-portal` (Example RollCall v2) — GAS WebApp + Sheets, 17 `.gs` files + 9 HtmlService modules (`app-*.html`), 261 tests, 7 sheets.

Original files are in Vietnamese (VI) — kept as `project-skill.VI.md` and `AGENTS.md` (VI) for reference. The published skills in `skills/` are the **generalized English** versions.

## What's here

- `AGENTS.md` — project law (11 immutable rules, deterministic edit, token system) — VI
- `project-skill.VI.md` — full project skill — VI
- `architecture-gotchas.md` — 2-phase model, EXTRA saga, staffIndex gap
- `deterministic-batch-runner.md` — multi-file CRLF patch runner skeleton
- `slot-fueled-classification.md` — slot-based `'Tự do'` = FREE design
- `mockup-design-language.md` — viewConfig mockup → app mapping

Use these to see how the generalized skills (`gas-webapp-review`, `webapp-ui-ux-audit`, etc.) were derived.
